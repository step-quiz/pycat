Comptador de vocals

Objectiu

Escriu un programa que llegeixi una paraula o frase i mostri quantes vocals conté. Compta les vocals a, e, i, o, u tant en minúscula com en majúscula. No comptis les vocals accentuades (à, é, etc.).

Exemples:

Entrada: hola     →  Vocals: 2
Entrada: Python   →  Vocals: 1
Entrada: AEIOU    →  Vocals: 5
Entrada: xyz      →  Vocals: 0

Simulador

Escriu el teu codi i prem ▶ Executa. El sistema provarà diverses paraules i frases.

💡 Pista

Recorre el text amb for c in text: i comprova si c.lower() in "aeiou". Acumula el comptador amb una variable que comenci a 0.
